# 프로젝트 스킬

이 폴더의 스킬은 Claude Code가 이 프로젝트에서 자동으로 인식합니다.
저장소에 함께 커밋되어 있으므로 다른 PC에서 clone해도 그대로 동작합니다.

## 출처

- `playwright-cli` — https://github.com/microsoft/playwright-cli
- 나머지 13개 — https://github.com/Leonxlnx/taste-skill (MIT, TASTE-SKILL-LICENSE 참조)

## 업데이트 방법

원본이 갱신되면 아래로 전역 설치본을 먼저 갱신한 뒤, 이 폴더에 다시 복사하세요.

    npx skills add Leonxlnx/taste-skill
    npx skills add microsoft/playwright-cli

설치 위치: `~/.agents/skills/`
